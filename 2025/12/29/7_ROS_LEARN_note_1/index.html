# ROS 关于通信链路的学习

通信架构的目的：抹平硬件架构带来的差异，保证数据稳定传输。

# 1. 两种主要通信架构

# TCP 协议

  • 特点：点对点，双方进行链接，三次握手确认，数据稳定可靠，双向通信。
  • 三次握手流程:
    1. 客户端 → 服务器: SYN (seq=x)
    2. 服务器 → 客户端: SYN+ACK (seq=y, ack=x+1)
    3. 客户端 → 服务器: ACK (ack=y+1)
    4. 连接建立完成。
  • 作用：三次握手是为了确保可以双向通信。

代码示例 (C - 创建 TCP Socket):

// 创建TCP服务器socket
int g_conn_sock = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
struct sockaddr_in addr = {
    .sin_family = AF_INET,
    .sin_addr.s_addr = IPADDR_ANY, // 监听所有网络接口
    .sin_port = htons(8080)        // 绑定端口
};
bind(g_conn_sock, (struct sockaddr *)&addr, sizeof(addr));
listen(g_conn_sock, 5); // 开始监听

# UDP 协议

  • 特点：单向发送，没有双方连接，不确保数据可靠 (无连接，不可靠传输)。
  • 应用：可一对一或一对多，类似 "喇叭"。
  • 优势：高速，便于进行实时传输。

代码示例 (Python - UDP 客户端):

# 创建UDP socket 并绑定到随机端口
with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as sock:
    sock.bind(('0.0.0.0', 0)) # 0表示随机端口
    # 发送数据
    sock.sendto(data, (target_ip, target_port))
    # 接收数据
    data, addr = sock.recvfrom(1024)

# TCP 与 UDP 对比

  • TCP: 趋于稳定可靠，数据为阻塞控制，速度慢，不可广播多播，类似点对点传文件。
  • UDP: 趋于及时传达，但不稳定不可靠，无阻塞，高速，可广播多播，类似打网游但容易丢包。

# 2. 字节序：字节存储顺序

  • 大端序 (Big-Endian): 由高位到低位，符合人类阅读习惯 (网络传输通常用大端)。
  • 小端序 (Little-Endian): 由低位到高位，利于计算机读取 (x86 等架构内部使用)。

示例:

(向右为内存地址增长方向，读取从左往右)

  • 大端序: .... 0x0a, 0x0b, 0x0c, 0x0d .... (0x0A0B0C0D)
  • 小端序: .... 0x0d, 0x0c, 0x0b, 0x0a ....

代码应用 (网络字节序转换):

// htons: Host to Network Short (主机序转网络序)
// ntohs: Network to Host Short (网络序转主机序)
size_t len = snprintf(buffer, sizeof(buffer),
                      "{\"port\": %"PRIu16"}",
                      ntohs(addr.sin_port)); // 将网络序端口转回主机序读取

# 3. mDNS

  • 概念：简单概括就是把局域网的某个设备的 IP 改为某个实例名 (如 micu-ros-car.local )。
  • 作用：局域网内设备互联不再需要查 IP, 直接用域名即可。

代码示例 (ESP32 启动 mDNS):

mdns_init();
mdns_hostname_set("micu-ros-car"); // 设置主机名
mdns_instance_name_set("micu-ros-car-instance");

# 4. socat (SOcket CAT)

  • 概念：网络工具，这里的用法主要是创建 虚拟串口，用于数据传输、端口转发。
  • 作用：将网络数据流转换为虚拟串口流，让 ROS 像操作串口一样操作网络数据。

代码示例 (Python 调用 socat 创建虚拟串口对):

# 创建虚拟串口对: pts0 <--> pts1
cmd = [
    "socat",
    "pty,raw,echo=0,link=./pts/pts0",
    "pty,raw,echo=0,link=./pts/pts1"
]
subprocess.Popen(cmd) # 在后台运行

# 5. JSON

  • 概念：用于数据交换的标准格式之一。
  • 特点：高兼容性，高扩展性，高易读性，使用广泛。
  • 应用场景: TCP 连接建立初期，交换配置信息 (如端口号、设备类型)。

代码示例:

  • Python (生成):

    import json
msg = json.dumps({"port": 12345, "type": "chassis"})
socket.send(msg.encode('ascii'))

  • C (解析):

    cJSON *root = cJSON_Parse(raw_data);
cJSON *item = cJSON_GetObjectItem(root, "type");
if (strcmp(item->valuestring, "chassis") == 0) { ... }

# 6. Socket

  • 概念：即 "接口" (插座), 封装好了 TCP 或其他底层协议，方便应用程序调用 API。

  • 本质：抽象了底层细节，是 应用程序 —— 网络协议 之间的抽象层。

  • 网络通信三要素:

    1. IP 地址：用于寻找主机 (逻辑地址)。
    2. 端口号：用于定位主机内的具体进程 (0~65535, 建议使用 1024 以上)。
    3. 传输协议：定义交互规则 (如 TCP/UDP)。

  • 核心函数流程:

    socket ()(创建) → bind ()(绑定) → listen ()/connect ()(连接) → send ()/recv ()(收发) → close ()(关闭)。
